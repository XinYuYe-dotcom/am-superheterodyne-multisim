# 接收端：选频、变频、检波与音频放大

## 为什么采用超外差结构

接收输入的载波频率可能变化，而固定频率的高增益放大和滤波更容易实现。超外差接收机先把所需射频变成固定中频，再进行放大和解调。

本项目使用约 455 kHz 中频，设计结构为：

`射频放大 → 与本振混频 → 中频选频/放大 → 包络检波 → 音频功放`

中放处约 455 kHz 的振荡保留着音频包络，随后由检波器取出低频电压变化。

## 1. 单机输入 V2

已保存参数：`Ac=5 mV`、`fc=1.005 MHz`、`m=0.3`、`fm=1 kHz`。这是已经调制完成的理想 AM 电压源，允许接收机独立运行。

V2 负责提供接收测试信号；VCC、V3/V4 为各级电路提供直流能量。当前输入配置见 [版本说明](04-status-and-limitations.md)。

## 2. Q5 高频小信号放大

- `C15` 输入隔直，信号叠加在由 `R16/R17` 建立的偏置上。
- `Q5` 提供射频放大。
- `L4=100 μH`、`C16=240 pF` 负责谐振选频。
- `R19=2.2 kΩ` 影响负载和选频带宽。
- `R18=1 kΩ` 稳定直流工作点；`C19=100 nF` 提供交流旁路。
- `C18=10 nF` 输出耦合，`R20=100 kΩ` 为后续端口提供回路。
- `C17=100 nF` 为供电去耦。

理想 LC 频率公式可用于起始估算，但晶体管、耦合电容、输入输出阻抗和模型寄生都会改变实际增益与中心频率。

## 3. Q6 本振及 Q7 缓冲

- `R23=47 kΩ/R24=10 kΩ`：本振晶体管偏置。
- `C21=100 nF`：基极交流旁路。
- `L5=47 μH`、`C22=33 pF`、`C23=270 pF`、`C24=1 nF`：振荡选频及反馈网络。
- `R25=680 Ω`、`R27=470 Ω`：发射极及反馈网络中的电阻。
- `R26=4.7 kΩ`：集电极回路阻尼/供电负载。
- `C25=4.7 pF`：与缓冲级弱耦合。
- `Q7`、`R28/R29/R30`：缓冲及其偏置、发射极负载。
- `C26` 隔直输出，`R31=1 kΩ` 电位器调节本振驱动量，`C27` 为供电去耦。

调谐后需要同时看频率、幅度和是否持续振荡。合适的本振驱动幅度有助于二极管环有效切换。更改参数时先停止仿真、确认单位，再重新运行并观察稳定段。

## 4. 二极管环混频与中频预选

`D1～D4` 使用 1BH62 模型，`T2/T3` 为 `2:1:1` 的变压器模型。三者组成平衡混频网络，射频与本振经过非线性过程产生变频分量。

`R32=1 kΩ`、`L6=100 μH`、`C28=1.22 nF` 选取中频分量；`R34=10 kΩ` 电位器调节中放输入，`C29=10 nF` 隔直。

目标中频与实际差频不匹配时，应先根据 `|f_LO−f_RF|` 检查。再结合通带宽度、驱动幅度和各级偏置定位失真来源。

## 5. Q8 中频放大

- `R35=47 kΩ/R36=10 kΩ`：基极偏置。
- `R37=100 Ω` 与 `R38=910 Ω`：发射极稳定及交流增益控制；`C30=100 nF` 旁路其中一段。
- `L7=100 μH/C31=1.22 nF`：约 455 kHz 的集电极谐振负载。
- `R39=2.2 kΩ`：负载/阻尼。
- `C32=10 nF`：输出耦合。
- `R40=10 kΩ`：输出对地回路。
- `C33=100 nF`：供电去耦。

检波前应检查该节点的 AM 包络是否连续，幅度是否足够，以及是否有削顶或断续。连续、幅度合适的包络是后级正常检波的基础。

## 6. D5 检波与两级 RC

`D5` 将正向峰值传给储能节点。`C34=470 pF` 在高频峰值附近充电，`R41=47 kΩ` 给它提供放电路径。

这个基本时间常数为约 `22 μs`；中频周期约 `2.2 μs`，1 kHz 音频周期为 `1 ms`。这是起始设计的量级比较，实际表现还取决于源阻抗、二极管压降、调制度和负载。

`R42=4.7 kΩ/C35=6.8 nF` 是后级低通。若仅把它当作低输出阻抗源驱动的理想一阶 RC，其截止频率约 5 kHz；实际响应同时受到检波器的非线性和前后级负载影响。

检波输出常带正直流偏置。对比前后波形时可先同时使用 DC 耦合。需要观察纯交流音频时可以使用 AC 耦合；比较电路调整前后的波形时，保持耦合模式和量程一致。

## 7. 音频与负载

`R43` 控制音量；`C36` 隔离检波直流，`R44` 提供输入偏置回路。TDA2030 放大低频信号，8 Ω 电阻模拟负载。

反馈电阻必须在反相输入处正确汇合：输出经 `R46=22 kΩ` 返回反相输入；反相输入另经 `R45=680 Ω` 和 `C37=22 μF` 到地。把反馈接到 680 Ω 的另一端会改变反馈网络。

验证该级时依次记录正负供电、静态输出电压、音频频率、增益与带载波形，即可将功放表现与前级检波结果对应起来。
