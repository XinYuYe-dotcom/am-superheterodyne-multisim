# 版本与测试配置

## 发布内容

本版对应 2026-11-22 提交的课程实验工程，包含发射端、接收端和完整系统三份原生设计。三份 `.ms14` 按原始字节保存，工程索引整理为相对路径，便于整包迁移。

## 输入配置

单独接收端通过 AM 测试源 V2 提供输入，参数为 5 mV 峰值、1.005 MHz 载波、1 kHz 音频、调制度 0.3。

当前完整版中，V2 与发射端衰减支路接在同一个接收输入节点。该理想电压源规定着节点电压。独立由发射端驱动的端到端验证列为后续测试：在调试副本中断开 V2，测量接收输入，并检查接收音频对发射音频变化的跟随情况。

## 参数与复现

- 本振调谐电容保存为 C22=33 pF，L5=47 μH。实际频率由整个振荡网络决定，通过运行测量记录。
- 已完成 ZIP 完整性、原生文件压缩块、XML 结构、文件哈希和工程相对引用检查。
- 后续复现包括在 Windows Multisim 14.3 中打开发布目录，运行各设计，记录稳态频率、幅度与波形。
- 扩展实验可继续测量增益、失真、灵敏度、选择性和带载输出。

## 使用范围

本项目用于有线连接的模拟通信仿真。8 Ω 电阻模拟音频输出负载。使用环境为 NI Multisim 14.3，器件模型与符号随原生文件保存。第三方材料说明见 [来源与许可](../THIRD_PARTY_NOTICES.md)。
