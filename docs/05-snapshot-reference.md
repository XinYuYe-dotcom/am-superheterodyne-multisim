# 参数快照与测量点

以下按提交的原生文件提取器件标称值和仪器连接。这些数值对应文件内保存的设置。早期截图的位号与本版可能不同，请以当前文件为准。

## 关键工作参数

- 接收测试源：5 mV 峰值、载波 1.005 MHz、音频 1 kHz、调制度 0.3。
- 本振：L5=47 μH；调谐电容 C22=33 pF。C21=100 nF 是另一只电容。
- 中频谐振：L6/L7=100 μH，C28/C31=1.22 nF，理想 LC 计算约 455.6 kHz。
- 基本检波：D5=1N5711，R41=47 kΩ，C34=470 pF。
- 检波后低通：R42=4.7 kΩ，C35=6.8 nF，孤立 RC 近似截止频率 4.98 kHz；接入实际前后级后会受负载影响。
- 音频功放：TDA2030，±12 V 供电，R48=8 Ω 模拟电阻负载。

## 示波器连接

接收端与完整版沿用相同的仪器编号。下列负端若未特别注明，均接公共地。

- **XSC1**：振荡器输出，C1/L1/C3/C7 公共节点。
- **XSC2**：缓冲后驱动，R8 滑动端与 C9 公共节点。
- **XSC3**：高频放大输出，C11 与 T1 原边上端。
- **XSC4**：Q4 集电极与输出负载上端；**负端接调制供电节点**，所以这是相对调制供电节点的差分读数。
- **XSC6**：接收高放输出，C18/R20/T2 原边上端。
- **XSC7**：本振缓冲输出，R31 滑动端与混频驱动节点。
- **XSC10**：混频后中频选频节点，L6/C28/R32 与 R34 上端。
- **XSC9**：中频放大输出，C32/R40 与 D5 左端。
- **XSC11**：检波后低通输出，R42 右端、C35 与音量 R43 上端。
- **XSC12**：TDA2030 输出与 8 Ω 负载上端。

XFC 是频率计，XSC 是示波器，XFG 是函数发生器。频率计图标中的“123”表示数字读数显示。检波后节点同时含音频、直流与残余纹波，频率计读数需要结合波形解释。
