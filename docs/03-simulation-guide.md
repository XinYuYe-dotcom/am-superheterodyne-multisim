# 打开、观察与验证

## 软件与文件

项目在 NI Multisim 14.3 环境中制作，原生文件扩展名为 `.ms14`，工程入口为 `.mp14`。推荐使用相同版本的软件环境。

下载后先完整解压，再打开工程。工程入口统一管理三份原理图，每份原理图独立运行仿真。

## 单独测试接收机

使用 `02_超外差接收端.ms14`，保留输入测试源 V2。它直接提供已经调制的 AM 信号。按射频、本振、混频、中放、检波、音频的顺序逐级观察。

V2 的已保存参数是：5 mV 峰值载波、1.005 MHz、调制度 0.3、1 kHz 调制。它与为电路供能的直流电源属于不同元件。

## 使用发射端进行收发联调

在 `03_完整收发系统.ms14` 的调试副本中选择发射端作为接收输入，按以下顺序操作：

1. 停止仿真，断开 V2 与接收输入的连接。
2. 保留发射端经隔直、衰减后到接收输入的连线；保留接收机全部直流供电及公共地。
3. 在输入耦合电容 C15 的信号源侧，实测射频幅度与载波频率。
4. 按实际载波匹配本振，使差频接近 455 kHz。
5. 再看中放包络、检波和音频输出。

验证方法：将发射机的音频从 1000 Hz 改为 800 Hz，确认接收音频也对应约 1.25 ms 周期，再恢复原频率。在选定发射端作为唯一射频输入后进行这项检查。

记录调整前后的发射输入与接收输出，可形成一组完整的端到端验证结果。

## 示波器怎么接

- 先确认正、负测量端。观察对地电压时，正端接目标节点，负端接该电路公共地。
- 差分测量时，读数是正端电压减去负端电压。
- 对比两个节点可使用同一台示波器 A/B 两通道，分别接同一个公共参考地。
- 对比前后节点时，统一 AC/DC 耦合、量程、纵向偏移和时间范围。
- “0”按钮用于显示通道零参考线。

观察射频或中频的细节需要微秒级窗口。观察 1 kHz 包络可先用 200 μs/Div。若毫秒范围内显示成密集色带，先缩小时间窗口再判断波形形状。

## 检波前后对照

可在同一次运行中设置：

- A 正端接 D5 右端、R41/C34 上端的检波节点。
- B 正端接 R42 右端、C35 上端的低通输出节点。
- 两个负端均接公共地，先都使用 DC 耦合、500 mV/Div、200 μs/Div。

比较同一时间段内的低频轮廓和高频纹波。基础检波节点通常带直流偏置，后级滤波节点应更平滑。最终音频经输入隔直后观察时，其参考电平和启动过渡又会不同。

若对负载效应进行隔离，在停止状态下暂时断开音量电位器 R43 上端与滤波节点的连接。需要恢复完整链路时再接回，避免把调试断点误当最终版本。

## 仿真时长、步长与内存

电路同时包含 MHz 载波和 kHz 音频。仅为看更多音频周期而放大最大计算步长，可能损害高频仿真的可靠性。可先以最大步长 20 ns、总时长 5 ms 做短时检查，再按目的延长并核查数值收敛。

**三份原生文件保留原有保存设置**。打开文件后检查仿真选项，再按上述建议设置最大步长与结束时间；求解器会在最大步长范围内自适应计算。

5 ms 可以观察若干个 1 kHz 周期。音频隔直电容、反馈电容和仪器耦合过程会影响启动时间，通过比较后续周期的重复性判断稳态。

多台示波器、频率计、保存历史数据和更小的步长会增加内存需求。发生过内存不足后，应先保护电路文件，再在新启动的进程中继续有限时长测试。

## Grapher 与历史数据

1. 运行当前设计后，打开 **View → Grapher**。
2. 选择与仪器编号相同的页面，例如 `Oscilloscope-XSC11`。
3. 通过图例区分 Channel A/B，并核对各曲线实际使用的坐标轴。
4. 右击图内进入 **Properties → Bottom Axis**，设置时间范围或使用 Auto-range。

例如观察 3～5 ms，可设 Min `0.003`、Max `0.005`。观察该段内 5 μs 的高频细节，可设 `0.003`～`0.003005`。

若启用 Discard data，旧数据可能已被丢弃，扩大坐标轴无法找回。需要回看时，在 Interactive Simulation 的 Analysis options 中检查 Continue without discarding previous data 和点数限制，再做有限时长的重新记录。历史保留与内存使用需要一起考虑。

示波器 T1/T2 显示两个测量游标所在的时刻。

## 频率计的使用边界

在干净的射频、本振或中频节点测量对应高频。在二极管后的未充分滤波节点，直流、音频和中频残留同时存在，计数器可能给出难以解释的跳读。

验证音频时优先测充分滤波后的稳定波形，或直接测相邻包络峰值/谷值的时间差。选择音频包络的相邻峰值计算周期。

## 结果状态如何描述

建议分别记录“模块有响应”“频率与幅度已测”“稳态波形已观察”“真实闭环已验证”。为各项记录对应波形、设置和测量值，便于复现。
